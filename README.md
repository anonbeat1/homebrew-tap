# Homebrew tap for Overheard

```bash
brew install --cask anonbeat1/tap/overheard
```

[Overheard](https://getoverheard.dev) is a Mac menu bar app that records your calls, transcribes them and makes them answerable from Claude. Apple Silicon, macOS 14.2+.

The app updates itself (Sparkle); `release.sh` in the [main repo](https://github.com/anonbeat1/overheard) bumps this cask on every release.
